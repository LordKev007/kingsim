# King's Grid Battle Practice

A standalone browser-based mockup of **King's Grid: Human vs CPU Battle Practice**.

## What this is

This is a concept prototype / interactive mockup for exploring how a digital **Human vs CPU** Battle Practice mode could work. It is a single-file HTML app that runs entirely in the browser.

## Files

- `index.html` — the playable mockup

## Run locally

Just open `index.html` in a browser.

## Host on GitHub Pages

1. Create a new GitHub repository.
2. Upload the files from this folder to the root of the repository.
3. In GitHub, go to **Settings** → **Pages**.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Save.
6. After GitHub finishes publishing, your site will be available at:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Current mockup notes

This version includes:

- 10×10 board
- Human vs CPU battle flow
- Beginner / Mid / Master CPU selection
- Random Battle Practice deployment
- 8-direction movement
- Interactive tile-by-tile wall placement
- Spear knockback selection
- 60-round cap and stalemate support

This is still a mockup rather than the final production implementation.
